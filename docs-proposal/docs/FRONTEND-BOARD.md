## 운영 규칙

- `In Progress`는 동시에 최대 1~2개만 유지한다.
- TASK 상태를 변경할 때 이 문서와 `HANDOFF.md`를 함께 갱신한다.
- 파일이 존재한다는 이유만으로 구현 완료로 간주하지 않는다.
- 각 TASK의 완료 조건과 검증 결과가 기록된 경우에만 Done으로 이동한다.
