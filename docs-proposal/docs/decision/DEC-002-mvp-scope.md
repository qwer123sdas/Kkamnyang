# 결정

현재 프론트엔드 단계에서는 RUN 활동과 핵심 경로 공유 기능의 안정화에 집중한다.

# 포함 범위

- Google OAuth
- 세션 유지
- login_id 최초 설정
- 러닝 기록 시작·종료
- Route Feed / Detail
- Like / Bookmark
- Profile / My Routes
- 공통 로딩·오류·빈 상태
- 실기기 통합 QA

# 제외 또는 후순위

- Naver OAuth
- Nearby Route
- Route Cluster
- Route History
- Comment
- 추천 알고리즘 고도화
- 실시간 위치 공유

# 주의

스켈레톤 파일이 이미 존재하더라도 해당 기능이 현재 MVP 구현 대상이라는 뜻은 아니다.
