# 결정

현재 프론트엔드 단계는 `RUN` 활동과 경로 공유의 안정적인 MVP 사용 흐름에 집중한다.

# 포함 범위

- Google OAuth
- 세션 유지
- 최초 `login_id` 설정 흐름
- 러닝 기록 시작과 종료
- Route Feed와 Route Detail
- Like와 Bookmark
- Profile과 My Routes
- 공통 로딩, 빈 상태, 오류 상태
- 실기기 통합 QA

# 제외 또는 낮은 우선순위 범위

- Naver OAuth
- Nearby Route
- Route Cluster
- Route History
- Comment
- 고도화된 추천 알고리즘
- 실시간 위치 공유

# 주의

스켈레톤 파일이 존재한다는 이유만으로 기능이 완료된 것은 아니다. 완료 여부는 TASK 완료 조건과 검증 결과를 기준으로 판단한다.
