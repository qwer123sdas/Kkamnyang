# 그래프 산출물

이 디렉터리는 graphify 산출물과 코드/문서 관계 분석 결과를 보관한다.

그래프 산출물은 분석 결과다.
원본 문서, Task 문서, 코드를 대체하지 않는다.

## 권장 파일

```text
YYYY-MM-DD-code-graph.md
YYYY-MM-DD-doc-graph.md
YYYY-MM-DD-feature-map.md
YYYY-MM-DD-dependency-notes.md
YYYY-MM-DD-graphify-output.json
YYYY-MM-DD-graphify-output.md
```

## 규칙

- 생성된 산출물은 이곳에 보관한다.
- 산출물은 관련 Task 문서에 연결한다.
- 사용자가 명시적으로 요청하지 않는 한 오래된 그래프 산출물을 삭제하지 않는다.
- Secret이나 실제 환경변수 값을 저장하지 않는다.
