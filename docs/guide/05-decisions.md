# 의사결정 기록

이 파일은 향후 AI 또는 개발자 작업에 영향을 주는 프로젝트 수준 의사결정을 기록하는 곳이다.

상세 구현 메모는 이 파일에 적지 않는다.
상세 구현 메모는 관련 Task 문서에 기록한다.

## 형식

```text
날짜:
결정:

관련 문서:
```
