# Project Requirements

Project

RouteLog

목표

사용자가 GPS 기반 운동 경로를 기록하고 공유할 수 있는 서비스 제공

---------------------------------------

# Scope

포함:

1. 러닝 GPS 기록

2. 경로 저장

3. 지도 표시

4. 공개/비공개 공유

5. 좋아요

6. 북마크

7. 근처 경로 조회

8. 유사 루트 그룹 조회

9. 동일 루트 반복 기록 조회

---

제외:

- 댓글
- 라이딩
- 등산
- 광고
- 결제
- 실시간 채팅
- AI 추천

---------------------------------------

# Functional Requirements

FR-001

사용자는 로그인 가능해야 한다.

지원:

- Google OAuth
- Naver OAuth

-----------------

FR-002

사용자는 활동 기록 시작 가능

입력:

활동 종류

- RUN
- RIDE
- HIKE

출력:

GPS 기록 시작

-----------------

FR-003

사용자는 활동 종료 가능

출력:

- 거리
- 시간
- 경로

-----------------

FR-004

사용자는 경로 저장 가능

입력:

title

description

visibility

-----------------

FR-005

사용자는 공개 경로 조회 가능

-----------------

FR-006

사용자는 좋아요 가능

-----------------

FR-007

사용자는 댓글 가능

-----------------

FR-008

사용자는 북마크 가능

FR-009

사용자는 유사한 러닝 코스를 조회할 수 있어야 한다.

입력:

route_id

출력:

유사한 경로 목록

조건:

시작점 반경 300m

종료점 반경 300m

거리 ±15%

---

FR-010

사용자는 동일 루트의 이전 러닝 기록을 조회할 수 있어야 한다.

입력:

route_id

출력:

activity 목록
